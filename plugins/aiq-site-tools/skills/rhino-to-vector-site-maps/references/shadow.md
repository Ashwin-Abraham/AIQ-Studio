# Seasonal shadows

Use [Ladybug analysis](../../ladybug-analysis/SKILL.md) for the selected ground or surfaces, or reuse recorded results whose geometry and settings match. Follow the shared [map specification](map-specification.md) for framing and export.

Use one board per date/time case with a common frame and scale. Draw editable result cells with sunlit areas in `#F5C341` and shaded areas in `#364C70`. Keep the context muted and site boundary visible. Key both colours; show missing results separately.

Label each board with the date, time, time basis, and UTC offset. For a below-horizon case, use grey `#878C94` and label **Sun below horizon** rather than reporting obstruction shade. State the grid size, receiver scope, and shaded-area percentage for daylight cases. These are snapshots, not daily sunlight hours.

Check case labels, result coverage, legend, and alignment. Retain full-receiver statistics when clipping artwork and link the analysis record and CSV. Inspect the exported PDF at print size.
