# Detailed Building Use

Create a separate board named **Detailed Building Use**, with the same framing as Building Use. Show every recorded building class in the selected extent, including rare and structural classes. Use a distinct solid colour for each exact class, as defined in [building use legend](building-use-legend.md). Use only the no-fill grey cross hatch for Unknown.

Use the reference's fixed class colours, subtype-only colours, Unknown style, and legend continuation rules. Preserve raw class and subtype values in the drawing data so conflicts remain traceable. Include all present classification keys in the legend; check that each colour key identifies one recorded class or subtype-only state. Reconcile the two use boards' feature counts and inspect colour separation at final print size.
