# Building Use

Show building footprints with the fixed recommended groups and colours in [building use legend](building-use-legend.md). Read that reference before classifying buildings. It defines the 20 reusable groups, exact class assignments, subtype fallbacks, and Unknown cross hatch. Show only present groups; keep their definitions and colours fixed across sites. Record the source class and subtype in editable sublayers and retain source properties unchanged.

Check source class/subtype coverage separately from final group coverage. Report conflicts and unsupported values. Apply the legend reference's checks before export.
