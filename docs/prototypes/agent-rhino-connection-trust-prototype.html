Can an agent use Rhino without taking control from Rhino?

Press the controls to test a proposed AIQ Studio connection. The agent uses aiq.exe. Each command uses a private named pipe and short-lived access. Rhino checks every request before it reads or changes a document.

Design question Can a command adapter and a private, per-session named pipe give Codex and OpenCode safe, resumable Rhino access while Rhino remains the only authority for document changes?

Trust rules under test

  1. 1Only typed operations on Rhino's allowlist can run.
  2. 2Each request names its session, document, revision, and access token.
  3. 3A material change needs approval for that request only.
  4. 4A new document revision makes an old request stale.
  5. 5Resume gives new access and does not restore an old approval.
  6. 6Each session has a private pipe and a separate journal.
