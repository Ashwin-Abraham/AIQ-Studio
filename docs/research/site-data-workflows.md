# Site-data workflow research index

Research corrected on 8 September 2026.

## Direction

The target is a layered, source-traceable 3D Rhino Site Model. It is not a generic site-data package.

The research now has two parts:

1. [Coordinate-to-Rhino site model](./coordinate-to-rhino-site-model.md) defines the location-independent path from an Area of Interest to a baseline Rhino Site Model.
2. [Location-specific site-data enhancement](./location-specific-site-data-enhancement.md) defines how to find, evaluate, and add data from the applicable authorities and local providers.

The human will select the test site later. A later Workflow Application will run both methods for that site. If data cannot become reliable geometry with reasonable effort, the workflow will record it in a cited Site Data Report.
